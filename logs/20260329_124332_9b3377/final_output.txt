Complete March 2026 Claude feature list:

1. March 2, 2026: Memory from chat history expanded to free users. What changed: Claude memory became available to free users on web, desktop, and mobile, including memory summaries and separate project memory. Who gets it: Free, Pro, Max, Team, and Enterprise users. Main limits: search past chats remained paid-only, memory synthesis updates on a 24-hour cycle, and memory import is a separate experimental feature limited to Free, Pro, and Max on web and Claude Desktop.

2. March 3, 2026: Skill-creator got testing and benchmarking upgrades. What changed: skill authors can now generate evals, run benchmark mode, use multi-agent parallel evaluation, compare versions with comparator agents, and tune descriptions so skills trigger more reliably. Who gets it: available in Claude.ai and Cowork, with plugin/repo access for Claude Code users. Main limits: this is mainly for people authoring Agent Skills, not general chat users.

3. March 9, 2026: Code Review launched for Claude Code. What changed: Claude Code can dispatch a team of agents on each PR, look for bugs in parallel, verify findings, rank severity, and post both a summary and inline comments. Who gets it: research preview for Team and Enterprise. Main limits: it is deliberately deeper and more expensive than the lighter Claude Code GitHub Action, and Anthropic says reviews average around 20 minutes.

4. March 11, 2026: Excel and PowerPoint got three related upgrades. What changed: Claude can now carry context across the Excel and PowerPoint add-ins and work across open files; Anthropic also added skills inside the add-ins; and it added a third-party deployment path for organizations using Bedrock, Vertex AI, Microsoft Foundry, or an LLM gateway. Who gets it: paid add-in users, plus org-managed third-party deployment for enterprise environments. Main limits: both add-ins and target files must be open, cross-app chat history is not saved between sessions, Team/Enterprise may need owner enablement, and current help docs say the third-party path does not yet support working across apps or skills.

5. March 12, 2026: Custom visuals in chat launched. What changed: Claude can generate inline interactive charts, diagrams, and other visuals directly in its responses, and you can download them or save them as artifacts. Who gets it: all Claude users on web and desktop. Main limits: beta only, not available in iOS, Android, or Cowork, and visuals are not saved automatically.

6. March 13, 2026: 1M context window became generally available for Opus 4.6 and Sonnet 4.6. What changed: standard pricing now applies across the full 1M context window, standard rate limits apply at every context length, media limits increased to 600 images/PDF pages, and no beta header is required. Claude Code on Opus 4.6 also got automatic 1M context for eligible plans. Who gets it: Claude Platform users of Opus 4.6/Sonnet 4.6, plus Claude Code Max, Team, and Enterprise users on Opus 4.6. Main limits: this is primarily a Platform and Claude Code feature, not a regular consumer-chat surface feature.

7. March 16, 2026: Extended thinking display control launched on Claude Platform. What changed: developers can set `thinking.display: "omitted"` so thinking text is suppressed while the signature is preserved for multi-turn continuity. Who gets it: Claude Platform users using extended thinking. Main limits: developer/API feature only; billing does not change.

8. March 17, 2026: Persistent Dispatch/Cowork thread launched across phone and desktop. What changed: Claude got one continuous thread you can access from Claude Desktop and Claude for iOS/Android, so context carries across tasks and Claude can spin work into Cowork or Claude Code sessions. Who gets it: research preview for Pro and Max; Anthropic said rollout started on March 17 for Max and over the next two days for Pro. Main limits: it requires both the desktop and mobile apps, your computer must stay awake with Claude Desktop open, and there is only one continuous thread.

9. March 18, 2026: Models API capability fields were added. What changed: `GET /v1/models` and `GET /v1/models/{model_id}` now return `max_input_tokens`, `max_tokens`, and a `capabilities` object so developers can discover what each model supports. Who gets it: Claude Platform developers. Main limits: this is a metadata/discovery API feature, not a consumer app feature.

10. March 23, 2026: Computer use arrived in Cowork and Claude Code, and Dispatch expanded further. What changed: Claude can directly use your computer when connectors are not enough, including clicking, typing, opening files, using the browser, and running dev tools; Anthropic also positioned this as making Dispatch more useful, including in Claude Code. Who gets it: research preview for Pro and Max. Main limits: on March 23 launch, Anthropic’s blog said support was macOS-only; Anthropic’s current help docs still describe Windows support as “coming soon.” It is early, runs outside Cowork’s VM sandbox, requires per-app permission, and Anthropic warns against using it with sensitive apps or data.

11. March 24, 2026: Auto mode launched for Claude Code. What changed: Claude Code got a new permissions mode where a classifier auto-allows lower-risk actions and blocks or escalates riskier ones before they run. Who gets it: research preview on Team at launch, with Enterprise and API rollout stated as coming in the following days. Main limits: safer than `--dangerously-skip-permissions`, but not risk-free; Anthropic still recommends isolated environments, and it can add some token, latency, and cost overhead.

12. March 25, 2026: Interactive apps came to Claude for iOS and Android. What changed: the mobile app can now render fully interactive apps directly in conversation, such as dashboards, task boards, and design tools, instead of only text responses. Who gets it: Claude mobile users. Main limits: this is best read as a new mobile rollout of the broader interactive-connectors system, not the first-ever launch of interactive connectors overall. Anthropic’s current help docs list examples including Amplitude, Asana, Box, Canva, Clay, Figma, Hex, and Slack.

What I did not count:

1. The March 13 to March 27 off-peak 2x usage promotion, because it was a temporary usage promotion, not a product capability.
2. Non-feature essays, customer stories, and workflow/thought-piece blog posts.
3. Commit-level or implementation-level changes from the `claude-code` GitHub changelog that Anthropic did not present as standalone March product launches.
