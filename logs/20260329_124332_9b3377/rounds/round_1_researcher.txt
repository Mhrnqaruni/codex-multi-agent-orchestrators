Claude’s Excel and PowerPoint add-ins can now share conversation context across both apps, so Claude can read from one and act in the other without you re-explaining the task. Anthropic also added Skills support in the add-ins and support for using them through an internal LLM gateway tied to Amazon Bedrock, Google Vertex AI, or Microsoft Foundry.
Sources: [Claude release notes](https://support.claude.com/en/articles/12138966-release-notes), [work across Excel and PowerPoint](https://support.claude.com/en/articles/13892150-work-across-excel-and-powerpoint)

3. March 12, 2026: Custom visuals in chat.
Claude can now generate inline charts, diagrams, and interactive visuals directly in responses. Anthropic says this is in beta, available to all users on web and desktop, and the visuals can be interacted with, downloaded, or saved as artifacts.
Sources: [Claude release notes](https://support.claude.com/en/articles/12138966-release-notes), [custom visuals in chat](https://support.claude.com/en/articles/13979539-custom-visuals-in-chat)

4. March 17, 2026: Persistent Cowork thread you can control from phone or desktop.
Pro and Max users got a persistent agent thread for Cowork that works across Claude Desktop and Claude for iOS/Android. The key change is continuity: one ongoing conversation where Claude keeps context across tasks, and can spin up Cowork sessions for knowledge work or Claude Code sessions for development work.
Sources: [Claude release notes](https://support.claude.com/en/articles/12138966-release-notes), [assign tasks to Claude from anywhere in Cowork](https://support.claude.com/en/articles/13947068-assign-tasks-to-claude-from-anywhere-in-cowork)

5. March 23, 2026: Computer use in Cowork and Claude Code.
Claude gained a research-preview “computer use” capability for Pro and Max plans. It can open files, use browser/dev tools, click, type, and navigate your screen to do tasks itself, with per-app permissions. Anthropic positions this as especially useful with the persistent mobile-to-desktop task handoff. Limitation: at launch this was on Claude Desktop with macOS support first, and Anthropic explicitly warns not to use it on sensitive apps/data.
Sources: [Claude release notes](https://support.claude.com/en/articles/12138966-release-notes), [computer use help article](https://support.claude.com/en/articles/14128542-let-claude-use-your-computer-in-cowork), [official blog post](https://claude.com/blog/dispatch-and-computer-use)

6. March 25, 2026: Interactive apps in Claude for iOS and Android.
Claude mobile gained support for fully interactive apps inside chats, not just text responses. Anthropic describes live charts, diagrams, dashboards, design tools, and other shareable visual assets rendered directly in the conversation. Their help docs list current interactive connectors including Amplitude, Asana, Box, Canva, Clay, Figma, Hex, and Slack.
Sources: [Claude release notes](https://support.claude.com/en/articles/12138966-release-notes), [interactive connectors in Claude](https://support.claude.com/en/articles/13454812-use-interactive-connectors-in-claude)

One notable adjacent March 2026 announcement, if you meant the broader Claude ecosystem rather than just the Claude app, was March 13, 2026: Anthropic made the 1M context window generally available for Opus 4.6 and Sonnet 4.6 on the Claude Platform, and included it in Claude Code for eligible plans. I’m treating that as platform/code infrastructure, not a core `claude.ai` app feature.
Source: [1M context GA announcement](https://claude.com/blog/1m-context-ga)
