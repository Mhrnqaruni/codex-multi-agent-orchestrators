What changed: Claude Code got a new permission mode where a classifier auto-approves lower-risk actions and blocks or escalates riskier ones, making long-running tasks less interruptive than the default mode and safer than skipping permissions entirely.
Who gets it: At launch, research preview on Team; Anthropic said Enterprise and API support would follow in the coming days.
Main limits: It is not risk-free, Anthropic still recommends isolated environments, and it can add some token, cost, and latency overhead.

10. March 25, 2026: Interactive apps expanded to Claude mobile.
What changed: Claude for iOS and Android gained support for fully interactive apps inside chats, letting live interfaces render directly in the conversation instead of only text. Current help docs list examples like Amplitude, Asana, Box, Canva, Clay, Figma, Hex, and Slack.
Who gets it: The March 25 release note was specifically about iOS/Android; current help docs show interactive connectors across Claude, Cowork, Desktop, and mobile.
Main limits: This appears to be a mobile expansion of an earlier interactive-connector capability, not the first launch of interactive connectors overall.
